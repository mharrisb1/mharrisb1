# Adding HTTP Proxy Support

We had some [open issues](https://github.com/evidence-dev/duckdb_gsheets/issues/99) and [PR attempts](https://github.com/evidence-dev/duckdb_gsheets/pull/92) popping up that really highlighted the need to support HTTP proxies, especially for corporate users.

DuckDB supports this already with their [HTTP Proxy](https://duckdb.org/docs/stable/core_extensions/httpfs/https#http-proxy) support using either one of these two options:

```sql
-- Using secret manager
CREATE SECRET http_proxy (
    TYPE http,
    HTTP_PROXY 'http_proxy_url',
    HTTP_PROXY_USERNAME 'username',
    HTTP_PROXY_PASSWORD 'password'
);

-- Using config options
SET http_proxy = 'http_proxy_url';
SET http_proxy_username = 'username';
SET http_proxy_password = 'password';
```

We decided that reusing this would be the best course of action.

[PR #102](https://github.com/evidence-dev/duckdb_gsheets/pull/102) added support for HTTP proxies. It was nice because all the work done in [PR #100](https://github.com/evidence-dev/duckdb_gsheets/pull/100) set this up to be a pretty trivial implementation.
