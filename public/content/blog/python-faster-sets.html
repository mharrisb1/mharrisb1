A gentle introduction to sets in programming

In programming, sets are a useful abstract data type that stores distinct elements. Python includes a data type set() that is an unordered collection with no duplicate elements. 


>>> animals = {"bat", "cat", "rat", "cat", "bat", "cat"}
>>> print(animals)
{'bat', 'cat', 'rat'}

Pretty simple. We'll come back and dive a little deeper but first, some math!

A gentle introduction to set theory

When exploring a new math subject I like to start out by going over the basic notation and then building up our mental model alongside increasing complexity of notation and formulas. For sets we'll start with the basics. This is how we would notate a collection of elements, x, y, and z.

S = { x , y , z }

The "cardinality" of this set (i.e. the number of elements it contains) is denoted like this:

| S | = 3

There are also special types of sets:

Notation Description Example
N Natural Numbers { 0 , 1 , 2 , 3 , ... }
Z Integers { ... , -2 , -1 , 0 , 1 , 2 , ... }
R Real { -5 , 0 , 1 2 , 3.75 }
C Complex { 3 + 4 i , − 2 + 5 i , 7 i , 5 }

The cardinality of all of these special sets above is infinite (∞) and paradoxically, they are not the same size.

You can also denote an empty set, or "null set":

∅ = { } , | ∅ | = 0

Set notation is also flexible and expressive so that you can notate a set like this:

S = { 2 , 4 , 6 , 8 , 10 , 12 , 14 , 16 , 18 }

You can also notate it more precisely like this:

S = { x ∈ ℕ ∣ x < 20 ∧ x mod 2 = 0 }

Don't be intimidated by all of those notations, they simply map to the following:

Concept / Meaning Math Symbol
Element of ∈
Such That ∣
Logical AND ∧
Modulo mod

Finally, we'll stop here for now with subsets and supersets. A "subset" is a set whose elements are all contained in another set.

A ⊆ B

A "superset" is a set that contains all elements from another set.

B ⊇ A

For our special sets mentioned above:

N ⊂ Z ⊂ R ⊂ C
